# Quick Start — بطاقة البدء السريع

## روابط مهمة / Key URLs

| Purpose | URL |
|---|---|
| لوحة المعلم (بعد الدخول) | `/dashboard` |
| تسجيل الدخول | `/login` |
| حضور المجموعة الأولى | `/attendance/group-1` |
| حضور المجموعة الثانية | `/attendance/group-2` |
| السجل | `/history` |
| العطلات | `/holidays` |
| الإعدادات | `/dashboard/settings` |
| فحص صحة النظام | `/api/health` |

## أول ٥ دقائق (First run)

1. افتح رابط الموقع → سيطلب إنشاء حساب المعلم.
2. أدخل البريد وكلمة المرور (٨+ أحرف) واحفظهما.
3. اضغط «إنشاء الحساب والبدء» — سيتم دخولك تلقائيًا.

## الإعدادات الافتراضية / Default settings

| Setting | Default |
|---|---|
| المجموعات | المجموعة الأولى + المجموعة الثانية |
| وقت الحلقتين | 16:00 – 17:00 |
| العطلة الأسبوعية | الجمعة + السبت |
| عطلات استثنائية | لا شيء |

كلها قابلة للتعديل من `/dashboard/settings` و `/holidays`.

## خطوات يومية (Daily flow)

1. افتح `/dashboard` قبل الحلقة — تأكد أن الحالة **مفتوحة الآن**.
2. انسخ رابط الحضور وأرسله للطلاب (أو استخدم الرابط المثبّت سابقًا).
3. راقب الأرقام تتحديث كل ١٥ ثانية.
4. بعد الحلقة: افتح `/history` لمراجعة اليوم.

## للطالب (Student flow)

1. يفتح رابط مجموعته.
2. يعبي: الاسم، المراجعة، عدد الأوجه، عدد السرد → **تسجيل الحضور**.
3. يظهر له رقم دوره ورمز تعديل خاص — يحتفظ بالرمز لتعديل تسجيله لاحقًا (٣٠ يومًا).
